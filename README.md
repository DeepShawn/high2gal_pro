## v3.13.1 · 快速反应数量调整

直接用浏览器打开 `index.html`。完整 HTML、CSS、JavaScript 及原有四语文本均在单个文件中，不依赖外部运行资源。

## 本次更新

| 难度 | 快速反应要求 |
| --- | --- |
| 简单 | 2次独立空格／两个触屏步骤，保持不变 |
| 普通 | 3次独立空格／三个触屏步骤，保持不变 |
| 困难 | 5个数字，数字1—5各出现一次 |
| 地狱 | 6个数字，数字1—6各出现一次 |
| 极限 | 8个数字，数字1—8各出现一次 |
| 神级 | 10个数字，数字1—10各出现一次 |

上方按钮与下方目标顺序分别随机排列；题目出现后不重新排列。每个数字只需按顺序完成一次，不是重复抽取可能相同的数字。

这项数量调整同步适用于校园正式快速反应、归家多步隐藏、DeepShawn试炼中的快速反应，以及新手快速反应／归家练习。一周模式继续按当日生效档位选择数量。

**本次不延长或缩短操作时间，不修改准备期、误按扣时、失败处罚、条件反射静止、难度倍率或独立对战数值。** 按钮增加后，困难以上会更难；真人难度尚未校准。

## 键盘与触屏

触屏／鼠标：按照下方顺序，点击上方按钮上的大数字。

键盘：按照目标按钮所在的位置按键，不是直接输入按钮上的大数字。位置1—9对应键1—9，**第10个位置对应0**，不是先按1再按0。支持主键盘及数字小键盘；长按自动重复不算多次操作。

8个和10个按钮在电脑与手机均使用两排，编号顺序为**先上后下，每排从左到右**；下方目标序列也按相同顺序阅读。8个是每排4个，10个是每排5个。

```text
神级的位置按键（不等于按钮上随机显示的目标数字）：
1  2  3  4  5
6  7  8  9  0
```

每个按钮标明对应位置键。手机宽屏、竖屏使用同一逻辑，避免10个目标横向挤在一行。按 Esc 暂停；全屏使用按钮或 Alt + Enter。

## 构建与测试

玩游戏不需要构建或安装依赖。

开发者重新生成相同 HTML：

```sh
python tools/build3131.py
```

构建只使用 Python 标准库。`tools/base_v3_13.html` 是本次收到的完整旧版源码；构建脚本使用校验替换，不会静默忽略找不到的修改位置。

专项自动测试使用 Python Playwright 与 Chromium：

```sh
python tests/test3131.py
```

测试脚本支持用 `CHROMIUM_BIN` 指定已安装的 Chromium 可执行文件。它使用真实 DOM、键盘和触屏模拟，但大部分计时与存储使用测试夹具；具体通过项、限制和结果见 `测试说明.txt` 与 `tests/results3131.json`。
